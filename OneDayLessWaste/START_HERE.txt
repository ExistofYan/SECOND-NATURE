ONE DAY, LESS WASTE - GESTURE RESOURCE FIX 1.0.3

READY-TO-RUN BUILD
1. Extract the ZIP completely into a new folder.
2. Open that folder in VS Code.
3. In the terminal, run: .\Start.cmd
   This serves the included dist folder using Python.
4. Open http://127.0.0.1:5174/ and allow the camera.
5. Show an open hand. Point, pinch thumb and index finger, then release.

DEVELOPMENT
Use Node.js 22.22.2 or later supported by your dependencies.
Run npm ci, then npm run dev.
Run npm test and npm run build after making changes.
Do not copy node_modules from an old project.

NETLIFY / STATIC HOSTING
Upload the ENTIRE dist folder to your existing site.
Its root must contain index.html AND art/, models/, mediapipe/, assets/, _headers.
Uploading index.html alone cannot load the illustrations or hand tracker.
After upload, hard-refresh the page with Ctrl+Shift+R.

TROUBLESHOOTING
- Camera access needs attention: allow this site to use your camera, then reload.
- Hand tracking resources could not load: read the named file/HTTP error and
  ensure the complete dist folder was uploaded. Camera permission cannot repair
  a missing model or WASM file.
- Never open index.html through file://. Use localhost or an HTTPS website.
